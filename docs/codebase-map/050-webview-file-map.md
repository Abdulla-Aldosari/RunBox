# Webview Side — File Map

All files share the **same `window` global scope** — loaded as ordered `<script>` tags. A function declared in an earlier file is available to all later files.

| Load Order | File | Purpose | Key Globals Declared |
| - | - | - | - |
| 1 | `media/state.js` | All mutable UI state + app data received from extension. `state.workspaceFolders` holds `Array<{ name, fsPath }>` received from the extension — populated only in multi-root workspaces. `aiState.modelsLoading` is `true` while the model list is being fetched from the API; set to `false` when the fetch completes or when no API key is saved for the selected provider. | `vscode`, `RUNBOX_EMPTY_VALUE`, `uiState`, `aiState`, `state`, `variableInputState`, `runConfirmState`, `aiExplainState`, `aiExplainLanguageState` |
| 2 | `media/icons.js` | All inline SVG icon strings. Includes `icons.folder` (used by the workspace selector bar in multi-root mode). | `icons` |

| 5 | `media/markdown-parser.js` | Lightweight Markdown → HTML converter. Supports: `##`/`###` headings, `**bold**`, `*italic*`, `` `inline code` ``, fenced code blocks, `- lists`, `1. lists`, `> blockquote`, and `\| tables \|`. No external dependencies. | `renderMarkdown`, `inlineMarkdown` |

| 12 | `media/modals/ai-check-status.js` | AI Check Status modal — shared by "Check Connection" and "Check Rate Limits" buttons in AI Settings. | 17 | `media/tabs/categories.js` | "Categories & Groups" tab (also hosts the AI Create entry point) | `renderCategoriesTab`, `renderCategoriesModal`, `bindCategoriesTabEvents`, `bindCategoriesModalEvents` (also used by the Commands tab quick-add-group button), `isManageModalNameDuplicate`, `getManageModalNameError` (format first via `getNameFormatError`, then duplicate), `updateManageModalNameHint`, `executeManageModalConfirm` |
| 18 | `media/render.js` | Master `render()` orchestrator + state hydration + event binding entry points. `render()` wraps the `#app` rebuild in `captureTableScroll()` / `restoreTableScroll()`. In the Recent, Favorites, and Commands tabs the page does not scroll: the tab card stretches to the panel bottom and only the table rows scroll inside `.table-scroll` under a sticky header. The Categories & Groups tab follows the same rule: `.manage-card` fills the panel bottom, `.manage-layout` fills the card, and only each `.manage-list` scrolls. `renderWorkspaceLabel()` renders the workspace label bar below the header: a plain text label in single-root mode; a `renderCustomSelect` dropdown (wrapperId `workspace-folder-select`) in multi-root mode, bound in `bindTopActions()` to post `setActiveWorkspaceFolder`. | `render`, `hydrateState`, `ensureSelectionDefaults`, `renderWorkspaceLabel`, `bindEvents`, `bindTopActions`, `bindTabs`, `bindModalDismiss`, `bindRowSelectionEvents` |
| 19 | `media/messages.js` | Single `window.addEventListener("message", ...)` block — all extension messages are handled inline with `if (message.type === ...)` branches. No named handler functions are exported. | _(none — all logic is inline inside the listener)_ |
| 20 | `media/main.js` | Loaded last. Contains: a `contextmenu` event listener (suppresses context menu unless text is selected), the tooltip IIFE (VS Code-style hover tooltips via event delegation), an IIFE that reports variable-field focus changes to the extension (`reportVariableFieldFocus`), and a single `vscode.postMessage({ type: "ready" })` call to signal the extension. No named post functions — all `postMessage` calls are inlined at their call sites throughout tabs and modals. | _(none)_ |
